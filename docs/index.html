Adapter and Ranking Flow

Dedicated adapters isolate ingestion logic, then ranked retrieval selects the most relevant knowledge context.

Input Adapters

  • brief-adapter normalizes problem, solution, and requirements.
  • figma-adapter handles Figma tools and optional sampled context.
  • image-adapter handles web, HTML, and direct image ingestion.

Scoring and Storage

  • Adapters produce a normalized scoring bundle.
  • Pipeline runs deterministic scoring and LLM narrative enrichment.
  • Run artifacts, findings, and context metadata are persisted.

Ranked Retrieval

  • Knowledge items are ranked by priority, matched tags, and scope weighting.
  • Session/project/user/organization candidates are merged and deduplicated.
  • Top-ranked items and relationships are injected into lens rendering.

Context and Validation Tools

create_project

Initialize a project workspace so reviews and rules stay organized by product area.

add_context_rule

Add constraints and quality criteria, such as accessibility, tone, or brand rules.

create_context_pack

Bundle rules and scenario context into a reusable pack for consistent validation runs.

validate_output_against_context

Score an output against the active context pack and return pass/fail evidence with reasons.

compare_validation_runs

Compare two or more validation runs to measure regression risk and improvement over time.

Why This Matters for UX Teams

UX teams increasingly work across fragmented tools, AI agents, and product-specific design rules. This project explores how an MCP server can act as a context bridge, allowing AI tools to review and validate design outputs against approved UX principles, design-system rules, and project constraints.
