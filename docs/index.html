ux_assistant
Capabilities Pipeline Tools Quick Start

MCP SERVER FOR UX TEAMS

Audit design quality with context, not guesswork.

ux_assistant reviews Figma links, web pages, screenshots, and HTML, then validates outputs against project rules and context packs so teams can ship with confidence.

GitHub Documentation

WHAT IT DOES

One platform, two operating modes

Review mode

Generate UX critique, identify friction and edge cases, and produce practical recommendations grounded in source evidence.

  • review_figma
  • review_input
  • challenge_design
  • improve_design
  • pitch_design

Validation mode

Enforce approved context rules, score compliance, generate correction prompts, and track regression across validation runs.

  • create_project
  • add_context_rule
  • create_context_pack
  • validate_output_against_context
  • compare_validation_runs

ARCHITECTURE

From raw input to actionable correction

A deterministic pipeline keeps results consistent and comparable.

  1. 01

    Input ingestion

    Accept Figma links, webpages, screenshots, image files, or HTML snippets.

  2. 02

    MCP orchestration

    Dispatch review and validation paths through a shared server pipeline.

  3. 03

    Scoring engine

    Apply rule findings and severity weighting to compute compliance outcomes.

  4. 04

    Narrative output

    Return reports, correction prompts, and run-to-run deltas for teams.

WHY THIS MATTERS

Move from subjective feedback to repeatable quality checks.

ux_assistant helps teams run UX governance with measurable evidence. Instead of isolated opinions, teams get shared standards, tracked compliance, and clearer remediation paths.
