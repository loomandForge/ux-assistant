02

An agentic review loop for UX quality.

The product direction stays focused on UX guardrails. The agent pattern is evidence gathering, model-assisted report writing, and correction guidance.

  1. Input capture

    Figma, web, image, HTML, or chat context

  2. Scoring engine

    Deterministic checks plus design evidence

  3. Report

    Scores, findings, risks, and rationale

  4. Correction prompt

    Tool-specific fixes for AI workflows

  5. Compare runs

    Track improvement and regression

05

Install the local MCP server in minutes.

The repo is pnpm-first and uses Node 20 with a real Node runtime for the native SQLite dependency. 

git clone git@github.com:loomandForge/ux-assistant.git
cd ux-assistant
nvm use
pnpm i --frozen-lockfile
pnpm run build
./setup.sh
pnpm run doctor

Trustworthy now, ambitious by design.

What works best today?
The local MCP review and validation workflow, including SQLite-backed runs and generated markdown reports.

Remote xmcp execution, deeper screenshot/web validators, hosted team storage, and paid SaaS workflows.

Environment checks make it easier to route AI-assisted UX review reports into the tools teams already use.
